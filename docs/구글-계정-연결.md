# 구글 계정 연결 (선택)

**연결하지 않아도 됩니다.** 기본 방식은 "링크 공유" 문서 가져오기입니다.

| | 링크 공유 (기본) | 구글 계정 연결 (선택) |
|---|---|---|
| 준비 | 문서 공유를 "링크가 있는 모든 사용자 - 뷰어"로 | 아래 순서대로 15분 정도, 처음 한 번 |
| 비공개 문서 | ✗ | ✓ |
| 형광펜 → 자막 버튼 | ✗ (`{{ }}` 기호를 쓰세요) | ✓ |
| 내 문서 목록에서 고르기 | ✗ | ✓ |
| 탭 고르기 | 첫 번째 탭, 또는 주소에 지정된 탭 | 탭 목록에서 고르기 |

> 링크 공유 방식은 구글의 공식 기능이 아닌 "내보내기" 주소를 씁니다. 구글이 바꾸면 동작이 달라질 수 있습니다.
> 링크 공유 문서는 주소를 아는 누구나 볼 수 있다는 점도 기억하세요.

---

## 왜 각자 만들어야 하나요?

설교 리모컨은 공용 구글 연결 키를 넣어 배포하지 않습니다.
"내 문서 목록 보기" 권한은 구글이 **심사**를 요구하는 권한이라, 공용 키를 쓰면 심사 전에는 사용자가 100명으로 제한되고 7일마다 연결이 풀립니다.
그래서 쓰는 사람이 **자기 구글 클라우드에 자기 키**를 만들어 넣습니다. 이 키는 그 맥의 `google.json`에만 저장됩니다.

## 만드는 순서

맥에서 사파리(또는 크롬)로 진행합니다. 구글 화면의 메뉴 이름은 때때로 바뀝니다. 비슷한 이름을 찾아 누르세요.

### 1) 프로젝트 만들기
1. https://console.cloud.google.com 에 구글 계정으로 들어갑니다. (처음이면 약관 동의)
2. 위쪽의 프로젝트 선택 상자 → **새 프로젝트** → 이름 `설교 리모컨` → **만들기**.
3. 만들어지면 위쪽 상자에서 그 프로젝트가 선택되어 있는지 확인합니다.

### 2) API 두 개 켜기
1. 왼쪽 메뉴 → **API 및 서비스** → **라이브러리**.
2. 검색창에 `Google Docs API` → 누르기 → **사용**.
3. 다시 라이브러리 → `Google Drive API` → **사용**.

### 3) 동의 화면 만들기
1. 왼쪽 메뉴 → **API 및 서비스** → **OAuth 동의 화면** (새 화면에서는 **Google 인증 플랫폼**) → **시작하기**.
2. 앱 이름 `설교 리모컨`, 사용자 지원 이메일 = 내 이메일 → 다음.
3. 대상(사용자 유형): **외부** → 다음.
4. 연락처 이메일 = 내 이메일 → 동의 → **만들기**.
5. **대상**(Audience) 화면 → **테스트 사용자** → **+ Add users** → 내 구글 계정(원고가 있는 계정) 입력 → 저장.

### 4) 연결 키(클라이언트) 만들기
1. 왼쪽 메뉴 → **사용자 인증 정보**(또는 **클라이언트**) → **+ 사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**.
2. 애플리케이션 유형: **데스크톱 앱** ← 꼭 이것으로. 이름은 아무거나.
3. **만들기** → 창에 나온 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사해 둡니다.

### 5) 설교 리모컨에 넣기
1. **서버가 켜진 맥**의 브라우저에서 `http://localhost:8080`을 엽니다. (아이패드에서는 할 수 없습니다)
2. 준비 화면 **4. 설교원고** → **구글 계정 연결 (선택)** 펼치기.
3. 클라이언트 ID와 보안 비밀번호를 붙여 넣고 **저장** → **구글 계정 연결**.
4. 구글 로그인 → **"Google에서 확인하지 않은 앱"** 경고가 나오면 **고급** → **설교 리모컨(으)로 이동**.
   (내가 만든 내 앱이라 괜찮습니다)
5. 권한 화면에서 **모든 항목을 체크**하고 **계속** → "구글 계정이 연결되었습니다".

## 7일마다 풀리는 문제

동의 화면의 게시 상태가 **"테스트"** 이면 연결이 **7일마다** 풀립니다. 계속 쓰려면:

1. 구글 클라우드 → **OAuth 동의 화면**(또는 **대상**) → 게시 상태 **앱 게시**(프로덕션으로 푸시) → 확인.
2. 설교 리모컨에서 **연결 해제** 후 다시 **구글 계정 연결**.

프로덕션으로 바꿔도 내가 혼자 쓰는 앱이라 구글 심사를 받지 않아도 됩니다. 연결할 때 "확인되지 않은 앱" 경고만 한 번 더 나옵니다.

## 요청하는 권한

모두 **읽기 전용**입니다. 문서를 고치거나 지우지 않습니다.
- 구글 문서 내용 읽기 (`documents.readonly`)
- 드라이브 파일 **이름·수정일** 보기 (`drive.metadata.readonly`) — "내 문서에서 선택" 목록용
- 이메일 주소 (연결된 계정 표시용)

연결을 끊으려면 준비 화면의 **연결 해제**를 누르세요. 구글 계정 설정 → 보안 → 타사 연결에서도 끊을 수 있습니다.

## 주의

- `google.json`에는 연결 키와 연결 정보가 들어 있습니다. **남에게 주거나 깃허브에 올리지 마세요.**
- 접속 비밀번호를 아는 기기는 연결된 계정의 문서 목록과 내용을 볼 수 있습니다.
