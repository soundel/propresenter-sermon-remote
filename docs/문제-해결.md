# 문제 해결

## 앱을 눌러도 아무 일이 없어요 (dmg 앱)

- 처음이라면 "그래도 열기"를 해야 합니다 → [설치 안내 A-1](설치-안내.md#1-앱-처음-열기).
- 브라우저 창이 뒤에 숨어 있을 수 있습니다. 사파리에서 `http://localhost:8080`을 직접 열어 보세요.
- 그래도 안 되면 `~/Library/Application Support/설교 리모컨/server.log` 파일을 열어 마지막 줄을 확인하세요.
  (Finder → 메뉴 막대 **이동** → **폴더로 이동** → 위 경로 붙여 넣기)

## 아이패드에서 접속이 안 돼요

1. 맥에서 설교 리모컨이 **켜져 있나요?** 맥 브라우저에서 `http://localhost:8080`이 열리면 켜져 있는 것입니다. (start.command 방식은 터미널 창을 닫으면 꺼집니다)
2. 아이패드와 맥이 **같은 와이파이(같은 공유기)** 에 있나요? 맥이 랜선이면, 아이패드는 그 공유기의 와이파이여야 합니다.
3. 주소를 정확히 입력했나요? `http://`로 시작하고 끝에 `:8080`이 붙습니다. (`https`가 아닙니다)
4. **학교·카페·회사 공용 와이파이**는 기기끼리의 통신을 막는 경우가 많습니다. 교회 내부망이나 **휴대폰 핫스팟**(맥과 아이패드 둘 다 연결)을 쓰세요.
5. 맥의 **방화벽**이 막고 있을 수 있습니다. 처음 켤 때 "node가 들어오는 연결을 허용하겠습니까?"가 나오면 **허용**.
   이미 거부했다면: 시스템 설정 → 네트워크 → 방화벽 → 옵션 → `node`를 "들어오는 연결 허용"으로.
6. 맥의 IP가 바뀌었을 수 있습니다. 터미널 창에 새로 나온 주소로 접속하세요. 매주 바뀌면 공유기에서 맥에 고정 IP를 주는 것이 편합니다.

## 비밀번호를 잊었어요

맥에서 브라우저로 `http://localhost:8080`을 열면 비밀번호 없이 들어갑니다. 준비 화면 맨 아래 **접속 비밀번호**에서 새로 정하세요.

## "포트 8080번을 이미 다른 프로그램이 쓰고 있습니다"

설교 리모컨이 이미 하나 켜져 있을 가능성이 큽니다. dmg 앱과 start.command를 **동시에 켜지 마세요.** Dock의 터미널에 다른 창이 있는지 보세요.
다른 프로그램이 8080을 쓴다면 터미널에서 폴더로 이동한 뒤 `PORT=8090 node server.js`처럼 다른 번호로 켤 수 있습니다.
(이 경우 구글 계정 연결은 다시 해야 합니다)

## "연결 실패" (1번 카드)

- ProPresenter가 켜져 있나요?
- ProPresenter → 설정 → Network → **Enable Network**가 켜져 있나요?
- 포트 번호가 ProPresenter에 표시된 것과 같나요?
- 설교 리모컨과 ProPresenter가 **같은 맥**이면 주소는 `127.0.0.1`. 다른 맥이면 ProPresenter 맥의 IP를 넣습니다.

## "슬라이드가 연결되지 않았습니다"

준비 화면 **2번**에서 이번 설교 프레젠테이션을 고르지 않았습니다. **목록에서 선택**으로 골라 주세요.
원고 속 버튼이 **빨간 테두리**이면 그 번호의 슬라이드가 프레젠테이션에 없다는 뜻입니다.

## "… 자막 틀이 정해지지 않았습니다"

준비 화면 **5번**에서 그 색의 메시지를 고르지 않았습니다. **메시지 목록 가져오기** → 그 색 옆에서 메시지를 고르세요.
메시지가 하나도 없다면 [ProPresenter 준비](ProPresenter-준비.md)를 먼저 보세요.

## 자막에 `${…}` 같은 이상한 글자가 나와요

메시지를 복제해서 토큰이 깨진 것입니다. ProPresenter 메시지의 글자 칸을 지우고 **토큰 추가…**로 다시 넣은 뒤, 설교 리모컨 5번에서 **메시지 목록 가져오기**를 다시 누르세요.

## 자막 주소와 본문이 바뀌어 들어가요

5번 카드에서 그 색 옆의 **서로 바꾸기**를 누르세요.

## 좌우 자막의 정렬·굵기가 서로 달라요

[ProPresenter 준비 → 주의 1, 2](ProPresenter-준비.md#꼭-알아야-할-주의점-시험하면서-겪은-것)를 보세요. (링크된 텍스트 대신 메시지 두 개, 한글 글꼴 지정)

## 구글 문서를 못 가져와요

- 주소가 `https://docs.google.com/document/d/…` 형태인가요? (구글 드라이브 폴더 주소나 공유용 짧은 주소는 안 됩니다)
- 계정을 연결하지 않았다면: 문서 **공유** → 일반 액세스 → **링크가 있는 모든 사용자** - **뷰어**.
- "Google Docs API를 사용으로 켜 주세요": [구글 계정 연결 2)](구글-계정-연결.md#2-api-두-개-켜기)를 다시 확인하세요.
- "연결이 만료되었습니다": 게시 상태가 "테스트"이면 7일마다 풀립니다. [7일마다 풀리는 문제](구글-계정-연결.md#7일마다-풀리는-문제)를 보세요.

## 형광펜을 칠했는데 자막 버튼이 안 생겨요

형광펜 인식은 **구글 계정 연결** 방식에서만 됩니다. 링크 공유 방식에서는 `{{ }}` 기호를 쓰세요.
또 너무 옅은 색(회색에 가까운 색)은 형광펜으로 보지 않습니다.

## 화면이 꺼지거나 버튼이 늦게 반응해요

- 아이패드 자동 잠금을 **안 함**으로.
- 맥은 랜선 연결을 권장합니다. 와이파이가 약하면 반응이 늦어질 수 있습니다.
- 위쪽의 점이 **빨간색**이면 ProPresenter와 연결이 끊긴 것입니다. 1번 카드를 확인하세요.

## 처음부터 다시 설정하고 싶어요

설교 리모컨을 끄고, 설정 폴더(dmg 앱은 `~/Library/Application Support/설교 리모컨/`, start.command는 프로그램 폴더) 안의 `state.json`(화면 설정·원고), `config.json`(연결), `google.json`(구글 연결), `auth.json`(비밀번호) 중 초기화할 파일을 지운 뒤 다시 켜세요.
`auth.json`을 지우면 새 접속 비밀번호가 만들어져 준비 화면 맨 위(또는 터미널)에 나옵니다.
