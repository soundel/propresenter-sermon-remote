# 유튜브 자막 (OBS) — 선택

무대 스크린과 유튜브 방송에 **자막을 서로 다른 모양으로** 띄우는 방법입니다.

- **무대 스크린**: 지금처럼 ProPresenter **메시지**(준비 화면 5번의 자막 틀)로 띄웁니다.
- **유튜브 방송**: 설교 리모컨이 직접 그린 자막 화면을 **OBS의 "브라우저" 소스**로 영상 위에 겹칩니다.

왜 따로 하나요? ProPresenter 메시지는 화면(Screen)마다 다른 디자인을 줄 수 없습니다.
Looks로는 메시지 층을 **켜고 끄기만** 할 수 있어서, 무대에는 큰 자막, 방송에는 작은 하단 자막처럼 나눌 수 없습니다.

```
아이패드 "다음" ─┬─▶ ProPresenter 메시지 ─▶ 무대 스크린 (무대용 자막)
                 └─▶ 설교 리모컨 자막 화면 ─▶ OBS 브라우저 소스 ─▶ 유튜브 (방송용 자막)
```

---

## 1. 설교 리모컨에서 켜기

1. 맥(설교 리모컨이 켜진 맥)의 브라우저에서 준비 화면을 엽니다. (`http://localhost:8080`)
2. **6. 유튜브 자막 (OBS)** 카드에서 **유튜브 자막 켜기**에 체크합니다.
3. **OBS에 넣을 주소** 옆의 **복사**를 누릅니다.
   - 주소는 `http://127.0.0.1:8080/overlay?key=…` 모양입니다. 끝의 `key`는 이 맥에서 처음 켤 때 만들어진 비밀 열쇠입니다.
   - OBS가 **다른 컴퓨터**에 있으면, 카드 아래에 보이는 `http://192.168.…:8080/overlay?key=…` 주소를 쓰세요. (같은 와이파이·공유기여야 합니다)
   - 주소는 이 맥의 준비 화면에서만 보입니다. 아이패드에서는 보이지 않습니다.
4. 디자인을 정합니다. 바꾸는 즉시 미리보기와 OBS에 반영됩니다.
   - 위쪽의 **일반 자막 / 성경 구절**을 눌러 **각각 따로** 정합니다. 예: 일반 자막은 띠 없이 크게, 성경 구절은 반투명 띠 위에 조금 작게.
   - **성경 구절**: 첫 줄이 성경 주소인 자막 (`{{요 3:16 / 하나님이…}}`, `{{파랑: 마 16:15 / …}}`)
   - **일반 자막**: 그 밖의 모든 자막 (`{{사랑은 받은 만큼 흘러갑니다}}`)
   - 두 쪽을 같게 하려면 **이 디자인을 … 에도 적용**을 누릅니다.

| 설정 | 뜻 |
|---|---|
| 화면 | **하단 자막**: 방송 영상 위에 글자만 겹침 / **풀스크린**: 배경 그림·영상으로 화면 전체를 덮고 그 위에 글자 |
| 배경 (풀스크린) | 고른 그림·영상이 화면 전체에 깔립니다. **검정**을 고르면 검은 화면. 아래 "배경 그림·영상 불러오기" 참고 |
| 배경 어둡게 (풀스크린) | 배경 위에 검은 막을 얼마나 진하게 덮을지. 글자가 잘 읽히도록 30~50%를 권합니다 |
| 위치 (하단 자막) | 화면 **아래** 또는 **위** (풀스크린은 항상 화면 가운데 높이) |
| 여백 | 하단 자막: 화면 끝에서 자막까지 거리 / 풀스크린: 좌우 여백 (1920×1080 기준 픽셀) |
| 글자 크기 | 본문 글자 크기. 글이 길면 자동으로 줄바꿈하고, 화면의 40%를 넘으면 글자를 조금씩 줄입니다 |
| 정렬 | 가운데 / 왼쪽 |
| 배경 띠 | 없음(흰 글자 + 그림자) / 반투명(검은 띠 위에 글자) |
| 띠 진하기 | 반투명 띠를 고르면 나옵니다. 5%(거의 투명) ~ 100%(검정) |
| 성경 주소 색 | (성경 구절만) 주소를 본문 위에 작게 이 색으로 띄웁니다. "원고의 자막 색"은 `{{파랑: …}}`의 색을 씁니다 |

### 배경 그림·영상 불러오기 (풀스크린)

1. 6번 카드에서 **일반 자막** 또는 **성경 구절**을 고르고, **화면**을 **풀스크린**으로 바꿉니다.
2. **배경** 칸의 **+ 그림·영상 불러오기**를 누르고 파일을 고릅니다. (여러 개를 한꺼번에 골라도 됩니다)
   - 그림: jpg, png, gif, webp / 영상: mp4, mov, m4v, webm (1GB까지)
   - **1920×1080** 크기가 가장 좋습니다. 비율이 다르면 화면에 꽉 차게 잘립니다.
   - 영상은 **소리 없이 반복** 재생됩니다. 아이폰 영상(HEVC)이 재생되지 않으면 H.264 mp4로 바꿔 주세요.
3. 다 불러오면 그 배경이 바로 골라집니다. 다른 배경을 누르면 바꿀 수 있고, 일반 자막과 성경 구절에 **서로 다른 배경**을 줄 수 있습니다.
4. 필요 없는 배경은 오른쪽 위 **✕**로 지웁니다.

- 불러온 파일은 설교 리모컨 데이터 폴더의 `overlay-media` 폴더에 저장되어, 앱을 업데이트해도 남아 있습니다.
  (dmg 앱: `~/Library/Application Support/설교 리모컨/overlay-media`)
- 같은 배경의 성경 구절을 이어서 띄우면 배경은 그대로 두고 **글자만** 바뀝니다. 영상도 처음부터 다시 시작하지 않습니다.
- 풀스크린 자막을 내리면 OBS 화면은 다시 투명해져 방송 영상이 보입니다.

## 2. OBS에 겹치기

1. OBS를 엽니다. 방송에 쓰는 **장면**을 고릅니다.
2. 아래 **소스** 칸의 **+** 버튼 → **브라우저**를 누릅니다.
3. **새로 만들기**에 이름을 `설교 자막`으로 적고 **확인**.
4. 속성 창에서:
   - **URL**: 복사한 주소를 붙여 넣습니다. (⌘+V)
   - **너비** `1920`, **높이** `1080`
   - 나머지는 그대로 두고 **확인**.
5. 소스 목록에서 `설교 자막`을 **맨 위**로 끌어 올립니다. (목록에서 위에 있을수록 화면에서 앞에 보입니다)
6. 방송 화면 크기가 1920×1080이 아니면(예: 1280×720), `설교 자막`을 오른쪽 클릭 → **변환** → **화면에 맞추기**.

확인: 준비 화면 6번 카드의 **유튜브에만 시험 자막 띄우기**를 누르면 OBS에 예시 자막이 뜹니다. (지금 고르고 있는 쪽 — 일반 자막 또는 성경 구절 — 의 예시) 무대 스크린(ProPresenter)에는 나가지 않습니다. **시험 자막 내리기**로 내립니다.

> 설교 리모컨을 껐다 켜도 OBS의 자막 화면은 몇 초 안에 저절로 다시 연결됩니다.
> 설교 리모컨을 새 버전으로 업데이트하면 자막 화면도 스스로 새로 고칩니다. (단, 1.1.0 이전 시험판에서 넘어올 때는 한 번 직접 새로 고쳐야 합니다)
> 오래 연결이 안 되면 `설교 자막` 소스를 오른쪽 클릭 → **속성** → 아래쪽 **현재 페이지의 캐시 새로 고침**.

## 3. ProPresenter: 유튜브용 화면에서 메시지 끄기

OBS가 ProPresenter 화면을 받아서(NDI, 캡처 보드, 화면 캡처 등) 방송한다면, 그 화면에도 무대용 메시지 자막이 같이 찍힙니다.
그러면 유튜브에 자막이 **두 번** 보입니다. 유튜브용 화면에서는 메시지 층을 꺼 주세요.

1. ProPresenter 메뉴 막대 → **Screens** → **Edit Looks…**
2. 지금 쓰는 Look(예: 기본 Look)을 고릅니다.
3. 화면 목록에서 **유튜브(방송)로 보내는 화면** 줄을 찾습니다.
4. 그 줄의 층 중 **Messages**(메시지)를 끕니다. 무대 스크린 줄의 Messages는 **켜 둡니다**.
5. 저장하고, 그 Look이 **지금 켜져 있는지(Live)** 확인합니다.

> 메뉴 이름은 ProPresenter 버전에 따라 조금 다를 수 있습니다. (만든 사람은 22.0.1에서 확인)
> 무대와 방송이 **같은 화면 하나**를 쓰고 있다면 Looks로 나눌 수 없습니다. 이때는 ProPresenter **Screens → Configure Screens**에서 방송용 화면(예: NDI 출력)을 하나 더 만들어야 합니다.

## 원고 쓰는 법은 그대로

| 원고 | 무대 스크린 | 유튜브 |
|---|---|---|
| `{{문구}}`, `{{파랑: …}}` (틀이 정해진 색) | 메시지로 뜸 | 함께 뜸 |
| 5번에서 **틀을 정하지 않은 색** | 안 뜸 (앞 자막은 내려감) | **유튜브에만** 뜸 |
| `✕ 자막 내림`, `[[자막지움]]` | 내려감 | 함께 내려감 |
| 슬라이드 `[[3]]` (슬라이드를 띄우면 자막을 내리는 설정일 때) | 자막 내려감 | 함께 내려감 |
| 설교 화면의 **자막·슬라이드 지우기** | 지움 | 함께 내려감 |

- 유튜브에만 띄우고 싶은 자막은, 무대에 쓰지 않는 색(예: `{{보라: …}}`)을 정해 5번에서 **틀 없음**으로 두면 됩니다. (빨간 테두리가 생기지 않습니다)
- 유튜브 자막을 끄면(체크 해제) 지금까지와 똑같이 동작합니다.

## 안 될 때

- **OBS에 "주소의 key가 맞지 않습니다"** → 주소를 다시 복사해 붙여 넣으세요. 키는 설교 리모컨 데이터 폴더의 `overlay.json`에 있습니다. 이 파일을 지우면 새 키가 만들어지고, OBS 주소도 새로 넣어야 합니다.
- **OBS 화면이 비어 있음** → 정상입니다. 자막이 없을 때는 투명합니다. 시험 자막을 띄워 보세요.
- **자막이 안 뜸** → 6번의 **유튜브 자막 켜기**가 체크되어 있는지, 설교 리모컨이 켜져 있는지 확인하세요.
- **다른 컴퓨터의 OBS에서 안 열림** → 같은 공유기에 있는지, 맥 방화벽이 `node`를 허용하는지 확인하세요. ([문제 해결](문제-해결.md#아이패드에서-접속이-안-돼요)과 같습니다)
