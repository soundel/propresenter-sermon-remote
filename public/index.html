접속 비밀번호를 입력하세요.

비밀번호는 맥의 서버 창(터미널)에 처음 한 번 표시됩니다. 잊었다면 그 맥에서 새로 정할 수 있습니다.

설교 리모컨

원고를 보면서 ProPresenter 슬라이드·배경·자막을 함께 넘깁니다.

아이패드에서 접속하기 이 맥에서만 보입니다

아이패드를 이 맥과 같은 와이파이에 연결하고, 사파리 주소창에 아래 주소를 입력하세요.

1. ProPresenter 연결

ProPresenter → 설정 → Network에서 Enable Network를 켜고, 거기 표시된 Port 번호를 입력하세요. 이 서버가 ProPresenter와 같은 맥에서 돌고 있다면 주소는 127.0.0.1 그대로 둡니다.

2. 설교 슬라이드 불러오기 선택

재생목록이나 라이브러리에서 이번 설교 프레젠테이션을 고르세요. 각 슬라이드의 번호가 표시됩니다. 자막만 쓴다면 건너뛰어도 됩니다.

3. 배경 불러오기 선택

슬라이드는 그대로 두고 배경만 바꿀 때 씁니다. ProPresenter 미디어 빈에서 배경을 모아 둔 재생목록을 고르면 번호가 붙습니다. 1번 배경은 기본 배경이 되어, 설교 화면 아래의 "기본 배경" 버튼으로 언제든 되돌릴 수 있습니다.

5. 자막 틀 자막을 쓸 때

원고의 {{문구}}(또는 구글 계정 연결 시 형광펜 칠한 문구)는 누르면 자막으로 뜨는 버튼이 됩니다. 색마다 ProPresenter의 어떤 메시지(자막 틀)로 띄울지 정하세요.
메시지 이름에 색 이름(예: "노랑 자막", "파랑 성경")이 들어 있으면 처음 가져올 때 자동으로 연결됩니다. 아무 색도 쓰지 않은 {{문구}}는 "기본" 틀로 뜹니다.
텍스트 토큰이 2개인 틀은 첫 줄(예: 성경 주소)과 나머지(본문)를 나눠 넣습니다.

6. 유튜브 자막 (OBS) 선택

무대 스크린에는 지금처럼 5번의 자막 틀(ProPresenter 메시지)로 띄우고, 유튜브 방송에는 설교 리모컨이 따로 그린 자막을 OBS에 겹칩니다. 그래서 유튜브 자막은 무대와 다른 위치·크기로 정할 수 있습니다.
OBS에서 소스 + → 브라우저 → 아래 주소를 붙여 넣고, 너비 1920 높이 1080으로 맞춥니다. 자세한 순서: docs/유튜브-자막-OBS.md
